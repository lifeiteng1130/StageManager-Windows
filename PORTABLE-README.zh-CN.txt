StageManager Windows 台前调度 · 本地定制版

完整解压后双击 StageManager.exe。Windows x64，Windows 10 2004 或更新版本。
此发布包自带 .NET 运行时，无须另外安装 SDK 或运行时。
请先退出 SillDeck 和其他 StageManager，避免两个窗口管理器相互干扰。

使用
1. 启动后自动识别普通桌面应用窗口，不需要将它们拖进容器。
2. 点击侧边卡片切换整组应用。组内窗口保留自己的桌面位置，可同时操作。
3. 先选中一个组，按住 Shift 点击另一个卡片，将其应用加入当前组。
   也可把卡片拖到当前桌面区域，或拖到另一张卡片上合并。
4. 右键卡片可将某个应用从组中拆出。不要点击“关闭”来退出调度；关闭组会关闭应用窗口。
5. 托盘图标右键菜单可打开设置或退出。退出会显示所有接管的窗口。
   在“设置 → 侧边栏 → 显示方式”选择“始终显示”或“自动隐藏”，修改即时保存。
   始终显示会悬浮于应用之上，可能遮住应用侧边；不会自动缩窄应用窗口。
   自动隐藏仅在鼠标靠近屏幕边缘时展开，移开后收起；拖拽或菜单操作期间保持显示。
6. 默认整组切换快捷键：按住 Ctrl+Alt+Win，再按 Tab / Shift+Tab / 1~9，松开修饰键确认。
   可在设置中修改快捷键。首次试用建议只用鼠标。

退出与恢复
正常退出使用托盘右键的“退出”。本版阻止退出期间尚未完成的切换再次隐藏窗口，
并尽力逐个恢复窗口及接管前的最小化状态。异常结束后再次启动会读取恢复日志。
如果上次异常退出后只想恢复窗口，不启动调度，可运行“恢复窗口.cmd”。
恢复命令要求 StageManager 已退出；若还在运行，请先从托盘退出。
不要删除 Data/parked-windows.json 后再尝试恢复，也不要把 Data 目录复制到其他电脑使用。

便携模式
portable.flag 标记开启便携模式；设置、日志和窗口恢复记录存放于本文件夹的 Data 中。
不自动添加开机启动。首次运行可能有未签名应用提示，本版没有商业签名。

本版范围
自动接管、多应用分组、整组切换主要复用上游当前实现。
新增退出生命周期保护、启动初始场景回退、逐窗口异常隔离、便携目录及恢复入口。
分组保存在本次运行的内存中，不承诺重启后恢复分组。
多显示器独立调度、虚拟桌面完整兼容和管理员应用控制不属于本次验收范围。
